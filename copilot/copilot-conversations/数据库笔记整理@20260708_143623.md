## 3. 关系代数写题套路

1. 确定从哪张表查  
   找出需要使用的关系，也就是 SQL 里的 `FROM`。

2. 确定查询条件  
   有筛选条件时，用选择运算 $\sigma$，对应 SQL 里的 `WHERE`。

3. 确定最后显示什么  
   用投影运算 $\pi$，对应 SQL 里的 `SELECT`。

基本结构：

```关系代数
π_列名(σ_条件(关系))
```

对应 SQL：

```SQL
SELECT 列名
FROM 关系
WHERE 条件;
```
